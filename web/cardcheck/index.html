STARSCOPE card check

Log shows from their thumbnails and line-ups on the iPhone. Runs on stardom-world.com in Safari from a bookmark.

1 · The bookmark (once)

  1. Tap Copy below.
  2. In Safari, open any page and tap Share › Add Bookmark. Name it Card check and save it to Favorites.
  3. Open Bookmarks, tap Edit, tap the Card check bookmark, clear its address and paste. Tap Done.

2 · The card check link (once)

  1. In the sheet's Apps Script: Project Settings › Script properties › Add, name CARDCHECK_KEY, value: a long random password of your own. It can only log matches (no exports, favorites or watch history), and you can change it any time.
  2. Redeploy the script (Deploy › Manage deployments › Edit › New version).
  3. Open www.stardom-world.com in Safari and tap the Card check bookmark. In the first box paste the web app address: the phone logger's link works as it is (everything after /exec is left out). In the second, the key. Both are kept in Safari on this phone; ⚙ changes them.

3 · Using it

  1. On any stardom-world.com page, tap Card check. It opens over the page: Started or a year, then a show.
  2. Scroll through the thumbnails. Fix a name with ?, set the venue once at the top, then Confirm all at the end, and Next for the next show.
  3. If Safari reloads the tab, tap the bookmark again: it reopens where you were.
